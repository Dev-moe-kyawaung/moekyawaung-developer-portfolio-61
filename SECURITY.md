
# Security Policy

## Supported Versions

Security updates are applied to the latest production version of this repository.

| Version | Supported |
| --- | --- |
| Latest | Yes |

## Reporting a Vulnerability

Please report suspected security vulnerabilities responsibly.

- Do not open a public issue for sensitive vulnerabilities.
- Send a private report through GitHub security reporting tools if enabled.
- If private reporting is unavailable, contact the maintainer directly through the contact method listed on the GitHub profile.

Please include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Screenshots or proof of concept if appropriate
- Suggested remediation, if known

You will receive acknowledgement as soon as possible, and valid reports will be reviewed and addressed in a reasonable timeframe.
